PeerStream

Local WebRTC P2P Demo
How this works: This demo simulates a peer-to-peer connection locally within your browser. It uses getDisplayMedia to capture your screen as the "Broadcaster", then uses the WebRTC RTCPeerConnection API to send that video stream, along with a Data Channel for chat, to a "Viewer" video element on the same page.
